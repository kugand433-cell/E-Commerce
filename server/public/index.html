ShopNest API Documentation

Complete API documentation for the ShopNest Multi-Vendor E-Commerce Platform backend.

Overview

Welcome to the ShopNest backend developer documentation. This REST API powers all actions across the ShopNest e-commerce platform, supports role-based permissions (Customer, Seller, Admin), handles product search & filtering, order placement, customer product reviews, file uploads, and admin panel stats.

Base URL
All API routes listed in this documentation are prefixed with: http://localhost:5000
Health Check
You can check server status anytime at: /api/health

Authentication & Authorization

ShopNest uses JSON Web Tokens (JWT) for authentication. To access protected routes, client applications must include the token in the HTTP Authorization header as a Bearer token:

Authorization: Bearer
POST /api/auth/register Public
Register a new user account as either a Customer or a Seller.
Request Body
{ "name": "John Doe", "email": "john@example.com", "password": "password123", "role": "customer" // Or "seller" }
Success Response (201 Created)
{ "success": true, "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "user": { "id": "60d0fe4f5311236168a109ca", "name": "John Doe", "email": "john@example.com", "role": "customer" } }
POST /api/auth/login Public
Login with email and password to receive a JWT access token.
Request Body
{ "email": "john@example.com", "password": "password123" }
Success Response (200 OK)
{ "success": true, "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", "user": { "id": "60d0fe4f5311236168a109ca", "name": "John Doe", "email": "john@example.com", "role": "customer" } }
GET /api/auth/me Required (All Roles)
Retrieve the current authenticated user's profile details.
Success Response (200 OK)
{ "success": true, "user": { "id": "60d0fe4f5311236168a109ca", "name": "John Doe", "email": "john@example.com", "role": "customer", "address": { "street": "123 Main St", "city": "Metropolis", "zipCode": "12345" } } }

Products API

Manage store inventory, retrieve product catalogs with filters, and handle product creation.

GET /api/products Public
Retrieve a paginated list of active products with search, category filtering, price bounds, rating filters, and sort options.
Query Parameters
Parameter Type Description
keyword String Text search in title, description, and tags
category String Category ID filter
price[gte] Number Minimum price bounds
price[lte] Number Maximum price bounds
rating Number Minimum product rating (e.g. 4)
sort String Sort field (price, -price, rating, -createdAt)
page Number Page index (default: 1)
limit Number Items per page (default: 12)
Success Response (200 OK)
{ "success": true, "count": 1, "totalPages": 1, "currentPage": 1, "products": [ { "_id": "60d0fe4f5311236168a109cb", "title": "Premium Wireless Headphones", "price": 199.99, "discountPrice": 149.99, "images": ["/uploads/headphones.jpg"], "rating": 4.5, "numReviews": 12, "stock": 45 } ] }
GET /api/products/:id Public
Retrieve details for a single product by ID (including populated category and seller).
Success Response (200 OK)
{ "success": true, "product": { "_id": "60d0fe4f5311236168a109cb", "title": "Premium Wireless Headphones", "description": "High fidelity sound with active noise cancelling...", "price": 199.99, "stock": 45, "images": ["/uploads/headphones.jpg"], "seller": { "_id": "60d0fe4f5311236168a109cc", "name": "SoundStore Ltd." }, "category": { "_id": "60d0fe4f5311236168a109cd", "name": "Electronics" } } }
POST /api/products Required (Seller/Admin)
Add a new product to the catalog.
Request Body
{ "title": "Gaming Keyboard", "description": "Mechanical switches with RGB lighting", "price": 89.99, "stock": 100, "category": "60d0fe4f5311236168a109cd", "images": ["/uploads/keyboard.jpg"] }
Success Response (201 Created)
{ "success": true, "product": { "_id": "60d0fe4f5311236168a109ce", "title": "Gaming Keyboard", "price": 89.99, "seller": "60d0fe4f5311236168a109ca" } }
PUT /api/products/:id Required (Owner Seller/Admin)
Update an existing product (Sellers can only modify their own items).
Success Response (200 OK)
{ "success": true, "product": { "_id": "60d0fe4f5311236168a109ce", "title": "Gaming Keyboard Pro", "price": 99.99 } }
DELETE /api/products/:id Required (Owner Seller/Admin)
Delete a product from the database.
Success Response (200 OK)
{ "success": true, "message": "Product removed successfully" }

Orders API

Process cart checkouts, manage customer order histories, and update status codes.

POST /api/orders Required (Customer)
Place a new order. Automatically reduces product stock.
Request Body
{ "items": [ { "product": "60d0fe4f5311236168a109cb", "quantity": 2 } ], "shippingAddress": { "street": "123 Main St", "city": "Metropolis", "zipCode": "12345", "country": "USA" }, "paymentMethod": "COD" // "COD" or "online" }
Success Response (201 Created)
{ "success": true, "order": { "_id": "60d0fe4f5311236168a109cf", "buyer": "60d0fe4f5311236168a109ca", "totalPrice": 299.98, "status": "pending", "isPaid": false } }
GET /api/orders/mine Required (Customer)
Retrieve all orders placed by the currently logged-in customer.
Success Response (200 OK)
{ "success": true, "orders": [ { "_id": "60d0fe4f5311236168a109cf", "totalPrice": 299.98, "status": "pending", "createdAt": "2026-06-08T09:49:05.000Z" } ] }

Reviews API

Handles product reviews and ratings. Enforces a rule where a customer can only write one review per product.

POST /api/reviews/:productId Required (Customer)
Add a rating and review for a specific product. Automatically updates the average rating of the product.
Request Body
{ "rating": 5, "comment": "Incredible sound quality, highly recommended!" }
Success Response (210 Created)
{ "success": true, "message": "Review added successfully", "review": { "_id": "60d0fe4f5311236168a109d0", "product": "60d0fe4f5311236168a109cb", "user": "60d0fe4f5311236168a109ca", "rating": 5, "comment": "Incredible sound quality..." } }

Upload API

Supports media asset upload capabilities for product images and profiles.

POST /api/upload Required (Seller/Admin)
Upload an image file. Configured for Cloudinary storage if environment variables are set; falls back to local disk storage.
Request Payload

Form-data field image containing the binary image file.

Success Response (200 OK)
{ "success": true, "imageUrl": "https://res.cloudinary.com/demo/image/upload/v1234/shopnest/keyboard.jpg" }

Admin API

System-wide administrative endpoints restricted to users with the role "admin".

GET /api/admin/stats Required (Admin Only)
Retrieve key platform metrics including user accounts, products, order tallies, and revenue totals.
Success Response (200 OK)
{ "success": true, "stats": { "usersCount": 120, "sellersCount": 14, "productsCount": 354, "ordersCount": 84, "totalRevenue": 14320.50 } }
GET /api/admin/users Required (Admin Only)
List all registered users on the platform.
Success Response (200 OK)
{ "success": true, "users": [ { "_id": "60d0fe4f5311236168a109ca", "name": "John Doe", "email": "john@example.com", "role": "customer", "isActive": true } ] }
